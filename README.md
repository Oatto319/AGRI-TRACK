# ระบบรายงานปุ๋ยอินทรีย์และวัสดุอินทรีย์รายเดือน

โปรเจค Next.js 16 สำหรับให้อำเภอบันทึกรายงานรายเดือน และให้จังหวัดดูสรุป/ดาวน์โหลด Excel

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000`

## เส้นทางหลัก

- `/` เข้าสู่ระบบตัวอย่าง
- `/district` Dashboard และประวัติรายงานของอำเภอ
- `/district/report` กรอก บันทึกร่าง หรือส่งรายงานรายเดือน
- `/province` Dashboard สรุปผลระดับจังหวัด
- `/province/table` ตารางรายอำเภอและดาวน์โหลด Excel
- `/province/settings` ตั้งค่าจำนวนครั้งที่ต้องรายงานต่อเดือนและวันกำหนดส่งของแต่ละรอบ
- `/api/settings` อ่าน/บันทึกการตั้งค่ารอบรายงาน
- `/api/export?from=YYYY-MM&to=YYYY-MM` ดาวน์โหลดไฟล์ Excel ตามช่วงเดือน

## ข้อมูลและการตั้งค่า

- รายชื่ออำเภอและช่องข้อมูลอยู่ใน `lib/data.ts`
- รายงานเก็บใน `data/reports.json` และสร้างไฟล์/โฟลเดอร์ให้อัตโนมัติเมื่อบันทึกครั้งแรก
- ที่เก็บข้อมูลแบบไฟล์เหมาะกับเซิร์ฟเวอร์เดียวที่มีพื้นที่เขียนข้อมูลถาวร ไม่เหมาะกับ serverless หรือหลาย instance; เปลี่ยนที่ `lib/store.ts` เมื่อต้องการใช้ฐานข้อมูล
- ระบบเข้าสู่ระบบในตัวอย่างนี้ยังไม่ตรวจสอบบัญชีจริง: ชื่อผู้ใช้ที่ขึ้นต้นด้วย `prov` จะเข้าหน้าจังหวัด ส่วนชื่ออื่นเข้าหน้าอำเภอที่เลือก ห้ามใช้กับข้อมูลจริงจนกว่าจะเชื่อมระบบยืนยันตัวตน

## รอบรายงานและการส่งช้า

- จังหวัดตั้งค่าที่ `/province/settings`: จำนวนครั้งต่อเดือน (1–4) และวันที่กำหนดส่งของแต่ละรอบ (31 = สิ้นเดือน) เก็บใน `data/settings.json`
- อำเภอกรอกแยกตามรอบ (เดือน + รอบที่) แต่ละรอบกรอกเฉพาะปริมาณของรอบนั้น ระบบรวมทุกรอบเป็นยอดของเดือน
- เมื่อส่งรายงาน ระบบบันทึกวัน-เวลาที่ส่งและเทียบกับวันกำหนด (เวลาประเทศไทย) หากเกินกำหนดจะแสดง "ส่งช้า" พร้อมวันที่ส่ง ในหน้ากรอก Dashboard อำเภอ ตารางจังหวัด และชีต "บันทึกการส่ง" ในไฟล์ Excel
- สถานะส่งช้านับจากการส่งครั้งแรก การแก้ไขแล้วส่งซ้ำไม่เปลี่ยนวันที่ส่งหรือสถานะ
- รายงานเก่าที่ไม่มีข้อมูลรอบ ถือเป็นรอบที่ 1 และแสดงว่า "ไม่มีบันทึกวันที่ส่ง"
- ยังไม่มีการตรวจสิทธิ์ (ล็อกอินเป็นตัวอย่าง) ใครเรียก `PUT /api/settings` ก็แก้การตั้งค่าได้ — ควรจำกัดสิทธิ์ก่อนใช้งานจริง
